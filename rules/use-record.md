description: When the user asks to remember or save a finding, propose the /record command — a user-invoked slash command, not a tool.
alwaysApply: true
---
The `/record` command writes durable findings (lessons, audits, notes) into `.omp/knowledge/records/`. It is a user-invoked slash command — you have no tool for it. When the user says "remember that…", "record this", or "save a note about…", propose `/record`. `/pitfall` is the one for things that just went wrong mid-task.
