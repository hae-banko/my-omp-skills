# Stack Overflow Module

> 从 web-search-agent.md 提取的技术问答专用策略

**触发场景**: 编程问答、代码实现、API用法

## 搜索源
- **Stack Overflow** and other Stack Exchange sites - technical Q&A
- **Technical forums** and discussion boards - community wisdom

## Exact Search Operators (Non-Redundant Patterns)
- **Stack Overflow Questions**: `site:stackoverflow.com/questions "exact error message"`
- **Tag-Constrained Search**: `site:stackoverflow.com [tag-name] "error message"`
- **Stack Exchange Network**: `site:stackexchange.com "topic"`

## Recommended Query Templates
1. `site:stackoverflow.com/questions "exact error"`
2. `site:stackoverflow.com [python] "API name"`
3. `site:superuser.com "command line error"`

## 查询策略 (Technical Q&A)
- Search with exact error string or API method signature
- Filter by relevant language/framework tags
- Prioritize accepted answers and top-voted solutions
